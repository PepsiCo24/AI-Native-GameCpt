- **数量:** 2 (primary wordmark, mark/icon)
- **尺寸:** primary 2048 × 2048 px canvas (wordmark centered, generous margin); mark 1024 × 1024 px
- **比例:** 1:1 canvas for both (safe for icons + scaling)
- **是否透明背景:** Yes (transparent PNG)
- **画面构图:**
  - **Primary wordmark:** the title uses a clean rounded geometric sans; hierarchy — main line `PHASE SHIFT`, secondary smaller line `ECHO GRID`.
